# 탄력근로 보상시간 정산

탄력근로 합의서와 근태 엑셀을 넣으면 연장·휴일·야간근로 보상시간을 주 단위로 정산하는 웹 페이지입니다.
계산 기준과 법적 근거는 [기획서.md](기획서.md)에, 버전별 변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
현재 버전은 화면 제목 옆에 표시되며, 누르면 변경 내역을 볼 수 있습니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다 (설치나 서버 필요 없음).
2. **탄력근로 합의서** 줄에 유형·시작일을 넣고 **합의서 표 입력**을 눌러 주차별 정규근무·연장근무·근로시간을 입력합니다.
   합의서 표를 복사해 첫 칸에 붙여넣으면 한 번에 채워집니다. 정산표 오른쪽 칸에서 바로 고칠 수도 있습니다.
3. **근무 기록 올리기**로 근태 엑셀(월별근무현황)을 올립니다. 여러 달이면 파일을 여러 개 한꺼번에 고르거나 화면에 끌어다 놓으세요.
4. 날짜 칸을 누르면 출퇴근, 정상·연장·야간, 지각, 연차·반차를 고칠 수 있습니다.

데이터는 이 브라우저에만 저장됩니다. 다른 PC로 옮기거나 백업하려면 **파일 → 데이터 파일로 저장**을 쓰세요.

## 계산 요약

- 하루 근로시간 = 엑셀의 정상(A) + 연장(B) + 야간(C). 비어 있으면 출퇴근 시각으로 자동 계산
- 주별 보상 = (실근로 − 합의서 근로시간)⁺ × 1.5 + 휴일근로(8h 이내 ×1.5, 초과 ×2.0) + 야간 × 0.5 − 지각
- 휴일: 일요일, 법정공휴일·대체공휴일·선거일·임시공휴일, 회사 지정 휴일. 토요일은 휴무일
- 합의서 기간 밖 날짜는 계산하지 않음

## 배포

빌드 과정이 없는 정적 파일입니다. 저장소를 GitHub Pages 등에 그대로 올리면 직원들이 각자 접속해 쓸 수 있습니다.

## 버전 규칙

- 기능 추가 → 가운데 숫자 (2.1.0 → 2.2.0)
- 버그 수정만 → 끝자리 (2.1.0 → 2.1.1)
- 화면·계산 체계를 크게 바꿈 → 앞자리 (3.0.0)
- 저장 파일의 `"version"`(데이터 형식 번호)과 브라우저 저장 이름 `flexcomp.v2`는 저장 구조가 바뀔 때만 바꿉니다. 화면 버전을 올려도 저장된 데이터는 그대로 이어집니다.
